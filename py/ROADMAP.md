# 影剪 · 开发路线图

> 单一规划文档：现状结论 + 版本化路线。功能级状态明细见 `FEATURES.md`。
> 节奏原则：**两端（Android/iOS）同一主题内同步推进**，一个主题做完再开下一个，避免双端越走越散。

## 一、现状结论（2026-08-27 代码盘点）

1. **编辑器核心链路两端已对齐**：裁剪/变速/倒放/旋转翻转/滤镜调色/文字图片水印/转场 xfade/去水印(模糊+马赛克)/画中画多轨/位置关键帧/静态贴纸/字幕(手动+语音转字)/变声/降噪/音频淡化——全部打通「UI → ViewModel → FilterBuilder → FFmpegKit 导出」。
2. **真正的缺口集中在四类**：
   - **半成品**（引擎已有、只差 UI 或入口）：画布比例/分辨率、BGM 混合（AUDIO 轨死代码）、一键静音、片尾 Logo 批量截断入口；
   - **音频侧空缺**：音频提取、替换、静音开关（同类最大短板）；
   - **画面能力**：自定义裁剪、背景纯色/图片、letterbox、定格；
   - **导出工具**：GIF、截图、压缩码率、格式转换、片头片尾。
3. **预览保真是共同欠债**：倒放/旋转/水印/画中画动态画面等均"以导出为准"，长期影响体验。

## 三、工程约定

1. 每个 vN.x 主题内：Python 参考脚本（如有）→ Android → iOS → 双端回归，完成后更新 `FEATURES.md` 对应行并打 tag。
2. FFmpegKit 精简包限制（无 eq/pad/drawtext/libx264 等）仍以 `VideoMergeAndroid/ARCHITECTURE.md` 记录为准；涉及新滤镜先用 Python 脚本在本机 full 版验证参数，再按平台能力选型。
3. 双端不对称的功能（如 iOS 实时预览、Android 的 Vosk）在 FEATURES.md 备注列显式标注，不追求实现方式一致、只保证功能一致。
